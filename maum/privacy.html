마음한편 개인정보 처리방침

시행일 2026년 11월 24일

마음한편은 현직 교사가 만든 아이폰 앱이에요. 하루의 마음을 한 편의 문장으로 남기고, 몸으로 하는 마음근력 활동과 나를 돌아보는 테스트를 해요. 진단이나 치료를 하지 않아요.

1. 받는 정보

  • 로그인 정보 : Apple · 구글 · 카카오로 로그인할 때 그 서비스가 알려 주는 로그인 번호와 이메일 주소(Apple은 이메일을 숨길 수 있어요). 이름 · 학교 · 전화번호는 받지 않아요.
  • 이 iPhone 에만 두는 정보 : 별명 · 학년 · 모드, 마음 기록(마음 날씨 · 좋은 점이나 위로 한 줄), 마음근력 활동 횟수, 테스트 답과 결과(내가 답한 우리 아이 · 배우자 테스트 포함), 고른 캐릭터 · 바탕 · 홈 모양, 오늘 해 볼 것 체크.

2. 한편이(AI)에게 보내는 정보

  • 마음 번역 · 물어보기 · 이야기 · 숨은 마음 도감 찾기에서 내가 직접 적어 보낸 글은 답을 만들기 위해 운영자의 서버(Cloudflare)를 거쳐 Anthropic(Claude)의 AI로 보내져요. 처음 보낼 때 앱에서 한 번 더 물어봐요.
  • 오늘의 문장 · 이번 주 총평에는 글이 아니라 숫자(최근 7일 기분 1~5, 활동 횟수, 연속 출석 날 수)와 테스트 결과 이름만 보내요.
  • 운영자의 서버는 보낸 글을 저장하지 않고 기록(로그)에도 남기지 않아요. 하루 쓸 수 있는 횟수를 세려고 로그인 번호와 횟수만 그날 하루 동안 두었다가 지워요.
  • Anthropic 은 API로 받은 내용을 AI 학습에 쓰지 않으며, 안전 점검을 위해 정해진 기간만 보관해요 (Anthropic 개인정보 처리방침).
  • 이름 · 연락처 · 학교 같은 개인 정보는 적지 말아 주세요.

3. 저장하는 곳과 쓰는 곳

  • 로그인 정보는 같은 계정으로 들어갈 수 있도록 구글 Firebase(Authentication)에 있어요. 교무실 타이쿤 · 먼저 플래너와 같은 로그인 계정을 써요.
  • 마음 기록과 테스트 결과는 서버로 보내지 않고 이 iPhone 안에만 저장해요. 운영자도 볼 수 없어요.
  • 광고 · 마케팅 · 다른 회사에 넘기는 데는 쓰지 않아요.
  • 힘든 날이 이어지거나 위험한 말이 보이면 도움 받을 곳(자살 예방 상담 109 · 청소년 상담 1388 · 112)을 보여 줘요. 위험한 말이 보인 글은 AI로 보내지 않아요. 누구에게도 알리지 않아요.

4. 이용 나이

마음한편은 만 14세 이상만 가입할 수 있어요. 앱 처음 동의 화면에서 나이를 확인하고, 만 14세 미만이면 가입하지 않아요. 만 14세 미만의 정보가 들어온 것을 알게 되면 바로 지워요.

5. 지우기 · 탈퇴

앱 홈 오른쪽 위 ☰ 메뉴 › 계정 지우기를 누르면 로그인 계정과 이 iPhone 의 기록을 모두 바로 지워요. 앱을 지워도 이 iPhone 의 기록은 함께 지워져요.

Privacy Policy (English summary)

Maum Hanpyeon (마음한편) is a daily mood journaling and self-reflection app made by a teacher. Sign-in uses Apple, Google or Kakao through Google Firebase Authentication; we keep only the sign-in user ID and the email provided by that service. Mood entries, activity counts, quiz answers and results, avatar and display settings are stored only on the device. When the user chooses to use the AI companion (Hanpyeon-i), the text they type is sent through our server (Cloudflare Workers) to Anthropic's Claude API to generate a reply; the user is asked for consent before the first send. Our server does not store or log that text; it keeps only the user ID and a daily usage count, deleted after the day. Daily sentence and weekly review features send only numbers (mood scores 1–5, counts) and quiz result names. Messages containing self-harm or violence keywords are not sent to the AI; instead the app shows helplines. Data is not used for advertising or tracking and is not shared for those purposes. The app is for users aged 14 and over. Users can delete their account and on-device data at any time (☰ › 계정 지우기). Contact: anstjsdud@sen.go.kr
