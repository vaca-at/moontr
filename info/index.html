1. 이용 안내

어떤 곳인가요

수능 생활과윤리·윤리와사상 기출문제를 풀고 복습하는 학습 도구입니다. 진선여자고등학교 3학년 학생들이 방과후에 자습할 때 쓰도록 만든 보충 학습 자료이며, 정규 수업에서 쓰는 도구가 아닙니다. 이용할지 말지는 학생이 스스로 정합니다.

두 과목이 있고, 화면 위쪽 [과목] 버튼으로 오갈 수 있습니다.

  • 생윤 만점 다이어리 — moontr.site/app · 생활과윤리
  • 윤사 만점 다이어리 — moontr.site/idea · 윤리와사상

이 안내는 위 두 곳에만 해당합니다.

로그인

  • 로그인하지 않아도 문제 풀이·검색·사상가별 원문 읽기는 모두 이용할 수 있습니다. 다만 기록이 남지 않습니다.
  • 기록을 남기려면 학번 5자리 + 닉네임(한글 5자 이내)으로 로그인합니다. 이름·이메일·전화번호는 받지 않습니다.
  • 학번과 이름은 친구들도 알기 때문에, 이름 대신 본인만 아는 닉네임을 열쇠로 씁니다. 기록이 담긴 문서의 이름도 학번과 닉네임을 섞어 만든 값이라, 닉네임을 모르면 남의 기록을 찾을 수 없습니다.
  • 한 학번은 처음 정한 닉네임으로만 다시 들어올 수 있습니다. 닉네임을 잊었으면 선생님께 재설정을 요청하세요.
  • 같이 쓰는 컴퓨터에서는 "이 기기에서 로그인 유지"를 켜지 마세요.

저장되는 학습 기록

로그인한 상태에서 다음이 저장됩니다.

  • 맞힌 문제·틀린 문제, 문항별 시도 횟수
  • 즐겨찾기, 문항별 메모, 내 노트
  • 형광펜으로 칠한 위치, 선지 O/X 판정 결과
  • 날짜별로 푼 문제 수(공부 잔디), 최초·최근 접속 시각
  • 문제를 풀 때마다 남는 응시 기록(문항·고른 번호·정답 여부·시각)

문항 오류 신고

문제 아래 [🚩 오류 신고]로 알려주세요. 신고가 접수된 문항에는 모든 학생 화면에 "신고된 문항" 표시가 뜹니다(누가 신고했는지는 표시되지 않습니다). 선생님이 확인해 고치면 표시가 사라집니다.

지켜주세요

  • 다른 사람의 학번으로 로그인하려 하지 마세요.
  • 메모·노트·신고 내용에 다른 사람의 개인정보나 비방을 적지 마세요.
  • 문항은 학습 목적으로만 이용하고, 무단으로 복제·배포하지 마세요. 기출문제의 저작권은 각 출제기관(교육청·한국교육과정평가원)에 있으며, 오답률 자료의 출처는 EBSi 오답률 통계입니다.

2. 개인정보 처리방침

이 안내는 생윤·윤사 만점 다이어리에만 적용됩니다.

2-1. 처리하는 정보

구분항목수집 방법
학생 학번(5자리), 닉네임(한글 5자 이내), 학습 기록(정답·오답·시도 횟수·즐겨찾기·메모·노트·형광펜 위치·선지 O/X·날짜별 학습량), 최초·최근 접속 시각 학생이 직접 입력·이용
응시 기록 학번, 닉네임, 문항 번호, 고른 선지, 정답 여부, 푼 시각 문제를 풀 때 자동 기록
오류 신고 문항 번호, 신고 사유(직접 쓴 글), 학번, 닉네임, 신고 시각 학생이 신고할 때
익명 접속 기록 기기 종류, 운영체제, 브라우저, 화면 너비 구간, 접속 날짜·시간대, 기기 구분용 무작위 값 사이트에 들어올 때 자동 기록 (학번과 연결되지 않음)
관리자(교사) 이메일 주소, 비밀번호 관리자 로그인(Firebase 인증)

이름·이메일·전화번호·주소·생년월일은 학생에게서 수집하지 않습니다. 다만 학번은 학교 안에서 개인을 특정할 수 있는 정보이므로 개인정보로 보아 관리합니다.

2-2. 처리 목적

  • 학습 기록을 저장해 오답노트·복습·학습 현황을 보여주기 위해
  • 여러 학생이 자주 틀리는 문항을 살펴 자료를 고치기 위해
  • 문항 오류를 확인하고 고치기 위해

2-3. 익명 접속 기록

화면을 어떤 기기에 맞춰 고칠지 정하려고, 들어올 때 기기 정보만 따로 모읍니다.

  • 남기는 것: 기기 종류(휴대폰·태블릿·컴퓨터), 운영체제, 브라우저, 화면 너비 구간, 접속 날짜와 시간대(몇 시), 그리고 기기마다 무작위로 만든 구분값
  • 학번·닉네임과 연결되지 않습니다. 학습 기록과는 완전히 다른 곳에 저장하며, 누가 접속했는지 알 수 없습니다.
  • 정확한 접속 시각은 남기지 않고 날짜와 시간대만 남깁니다.
  • 로그인하지 않아도 이 기록은 남습니다. 브라우저 기록을 지우면 기기 구분값도 새로 만들어집니다.

2-4. 쿠키·분석 도구

  • 쿠키를 사용하지 않습니다.
  • 구글 애널리틱스 등 바깥 분석 도구를 사용하지 않습니다. 위 접속 기록은 이 사이트 안에만 저장됩니다.
  • 브라우저 저장소(localStorage·sessionStorage)에 기기 안에만 남는 값이 있습니다: 로그인 유지를 켠 경우의 학번·닉네임, 글씨체·디자인·글자 크기·다크모드 설정, 타이머·형광펜·선지 O/X 모드, 오늘의 10문제 목록. 이 값은 서버로 보내지 않으며, 브라우저 기록을 지우면 함께 지워집니다.

2-5. 보관과 파기

  • 학년말에 파기합니다. 학습 기록과 응시 기록 모두 해당 학년이 끝나면 지웁니다.
  • 응시 기록(문제를 풀 때마다 쌓이는 기록)은 2027년 1월 31일에 일괄 삭제하며, 이후로도 매 학년말에 같은 방식으로 정리합니다.
  • 학년 도중이라도 요청하시면 지워드립니다(아래 열람・삭제 요청 참고).
  • 익명 접속 기록도 같은 때에 함께 지웁니다.
  • 자동으로 지워지지는 않고, 위 시점에 교사가 직접 지웁니다.

2-6. 제3자 제공

학생의 정보를 다른 기관·업체에 제공하지 않습니다. 아래 외부 서비스는 서비스를 돌리기 위해 쓰는 곳이며, 그 목적 밖으로는 쓰지 않습니다.

2-7. 안전을 위한 조치

  • 기록 문서의 이름을 학번과 닉네임을 섞어 만든 값(SHA-256)으로 만들어, 닉네임을 모르면 남의 기록에 접근할 수 없습니다.
  • 문항 등록·수정·삭제, 학생 현황 보기, 신고 열람은 지정된 교사 계정으로 로그인한 경우에만 가능하도록 데이터베이스 보안 규칙으로 막아두었습니다.
  • 오류 신고 내용과 신고자는 교사만 볼 수 있습니다. 학생 화면에는 "신고된 문항"이라는 표시만 나타납니다.

2-8. 이용 안내 방식

  • 학생들에게 수업 시간에 말로 안내하고 있습니다. 방과후 자습에서 스스로 선택해 쓰는 보충 자료라, 별도의 가정통신문이나 동의서는 받지 않습니다.
  • 로그인은 선택입니다. 로그인하지 않으면 어떤 기록도 남지 않습니다.
  • 고등학교 3학년 학생을 위한 자료로, 만 14세 미만을 대상으로 하지 않습니다.

2-9. 안내 변경

  • 스스로 할 수 있는 것 — 메모·노트는 언제든 고치거나 지울 수 있고, 즐겨찾기·형광펜도 해제할 수 있습니다. [로그아웃]을 누르면 이 기기에 저장된 로그인 정보가 지워집니다(서버의 학습 기록은 남습니다).
