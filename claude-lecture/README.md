# 클로드 연수 준비

선생님들께 할 클로드(Claude) 연수를 준비하는 폴더예요. 아직 코드는 없고 읽을거리만 있어요.

웹으로 보기: https://moontr.site/claude (아래 txt 를 그대로 읽어 와요. txt 를 고치면 페이지도 바뀌어요)

## 파일

| 파일 | 내용 |
|---|---|
| `클로드로_할_수_있는_것.txt` | 클로드로 할 수 있는 것 전부 (교사 업무 · 수업 · 일상 · 인스타 · 책에서 다루는 것) |

## 쓰는 순서

1. `클로드로_할_수_있는_것.txt`를 읽으며 직접 해 본 것은 `[v]`, 강의에 넣을 것은 `[*]`로 바꿔요.
2. `[*]`가 붙은 것만 모아 강의 흐름을 정해요.
3. 흐름이 정해지면 연수 계획서 · 발표 자료 · 실습 자료를 이 폴더에 만들어요.

## 강의 구성 처음 생각 (3시간 기준)

| 순서 | 내용 | 시간 |
|---|---|---|
| 맛보기 시연 | 말 한마디로 다운로드 폴더 · 바탕화면 정리 | 10~15분 |
| 1부 | 클로드와 친해지기: 잘 묻는 법 · 파일 넣기 · 안전 규칙 | 40분 |
| 2부 | 업무에 바로 쓰기: 공문 · 안내문 · 댓글 다듬기 · 교안 분석 · 발표 자료 | 50분 |
| 3부 | 바이브코딩: 우리 반 웹앱을 말로 만들기 (데이터 · 알고리즘 실험실 사례) | 70분 |
| 4부 | 정리: 언제 쓰고 언제 쓰지 말까, 내 학교에서 해 볼 과제 하나 | 20분 |

## 정해야 할 것

- 대상: AI를 처음 쓰는 선생님 / 이미 쓰는 선생님
- 시간: 1시간 / 3시간 / 하루
- 실습 환경: 노트북 · 클로드 계정(무료 · 유료) · 학교 PC 설치 가능 여부
