# ✍️ 블로그 글쓰기 (moontr.site/blog)

재료(메모 · 사진 · 깃허브 커밋)를 넣으면 AI가 **문선생 블로그(blog.naver.com/moontools) 형식 그대로** 글을 써 주는 도구.
1단계는 문쌤 혼자 써요. 쓰다가 괜찮으면 다른 선생님도 쓰게 바꿔요.

## 글 종류

| 종류 | 재료 | 짜임 (예전 글에서 뽑음) |
|---|---|---|
| 연수 후기 | 연수 이름 · 날짜 · 장소, 인상 깊었던 것, 배운 점, 내 수업에 적용할 점, 교안 글, 사진 | 인사 → 어떤 연수였나요? → 인상 깊었던 장면 → 이런 걸 배웠어요 → 제 수업에 이렇게 적용해 볼게요 → 연수 사진 공유 → 인사 |
| 개발 일기 | 앱, 만든 것 · 고친 것, 어려웠던 점, 반응, 다음 계획, **깃허브 커밋(앱 폴더별로 불러오기)**, 스크린샷 | 인사 → ○○는 어떤 앱인가요? → 시간 순으로 정리한 개발 일정(표) → 숫자로 본 개발 일지 → 만들면서 기억에 남는 일들 → 앞으로 이렇게 하고 싶어요 |
| 앱 소개 | 위와 같음 | 요약 상자(━━━) → ○○은 어떤 앱인가요? → 이 앱을 만든 이유 → 시작하는 방법 → 주요 기능 → 이 앱의 특징 → 지금 바로 써 보세요 → 링크 카드 |

## 문선생 블로그 형식 (2026-11-22, 글 7편을 읽고 정리)

- **제목**: 검색이 잘 되는 긴 제목. "○○ 추천! … '앱(영문)' … 무료 기능", "○○ 기록 : 부제"
- **첫머리**: 스티커 → "안녕하세요, 문선생입니다 :)" → 2~4줄 소개. 앱 글은 ━━━ 요약 상자
- **부제목**: 블로그 **인용구**, 질문하거나 말 거는 투
- **본문**: 가운데 정렬, 한 줄에 한 구절씩 짧게, 문단 사이 빈 줄, ① ② ③ · ■ · `·` · `-` 목록, 일정 · 목록은 표
- **말투**: "~해요 / ~했어요!" 느낌표, "~인데요!", "~더라고요!", 이모지는 가끔
- **끝**: "지금 바로 써 보세요 → 주소" + 링크 카드 + 댓글 부탁 + "긴 글 읽어주셔서 감사합니당" + 스티커 + 해시태그 한 줄

형식을 고치려면 `datalab/server/worker.js` 의 `BLOG_BASE` 를 고치고 서버를 다시 올려요 (`cd datalab/server && npx wrangler@4 deploy`).

## 쓰는 법

1. 글 종류 고르기 → 재료 넣기 (짧게 적어도 돼요) → 사진 넣기 (끌어다 놓기 · 붙여넣기)
2. [✍️ 블로그 글 쓰기] → 오른쪽에 블로그처럼 미리보기
3. 제목 3개 중 하나 고르기, 글을 눌러 바로 고치기, 또는 [AI로 고치기]
4. [📋 블로그에 붙여넣기용 복사] → 네이버 블로그 본문에 붙여 넣고 `【사진 1】` `【인용구】` `【스티커】` `【링크 카드】` 자리만 바꾸기
5. 인스타 · 스레드 글도 같이 복사

## 어디에 무엇이

| 무엇 | 어디 |
|---|---|
| 화면 | `blog/index.html` (관리자 구글 로그인, 이름 없는 기본 Firebase 앱) |
| AI | 데이터 실험실 서버 `moontr-datalab-ai` 의 `POST /blog` (관리자 로그인 표 확인, 비밀값은 그 서버의 `ANTHROPIC_API_KEY`) |
| 저장 | Firestore `blog_posts` (관리자만, `firestore.rules`). 보안 규칙 게시 전에는 그 기기(localStorage)에만 |
| 사진 | 저장하지 않아요. 글 쓸 때만 1280px 로 줄여 AI 에 보내요 |
| 커밋 | 깃허브 공개 저장소 API (`vaca-at/moontr` 앱 폴더별, 아이아이노트는 `vaca-at/iinote` 전체). 비공개로 바꾸면 못 읽어요 |

## 나중에 다른 선생님도 쓰게 하려면

- 로그인: 관리자 한 명 → 구글 · 카카오 일반 로그인 (이름 붙은 Firebase 앱으로, AGENTS.md 규칙)
- 형식: `BLOG_BASE` 를 사람마다 — 자기 블로그 주소를 넣으면 글 몇 편을 읽어 형식을 뽑아 저장
- 저장: `blog_posts/{uid}/posts/{id}` 처럼 사람마다 나누기
- AI 사용량: 하루 횟수 제한 (데이터 실험실의 Quota 방식)
- 블로그 서버를 데이터 실험실 서버에서 따로 떼기 (`blog/server`)
