        🖥 바탕화면으로 만들기

        컴퓨터를 켜면 교무실 타이쿤이 바탕화면 배경으로 계속 움직이게 할 수 있어요. 주소는 https://moontr.site/tycoon/ 하나예요. (위 [🖥 바탕화면으로 쓰기] 단추를 누르면 주소 복사 단추가 있어요.)

        • 윈도우 · Lively Wallpaper (무료, 가장 추천)
          1. Microsoft Store에서 Lively Wallpaper를 설치해요.
          2. Lively 위쪽 [+] 배경 추가 → URL 입력에 주소를 붙여 넣어요.
          3. 목록에 생긴 교무실 타이쿤을 누르면 바탕화면이 바뀌어요.
          4. 로그인 화면이 보이면 그 배경의 ⋯ → 사용자 지정(또는 바탕화면 상호작용 켜기)으로 한 번 로그인해요.
          5. Lively 설정 → 일반 → 윈도우와 함께 시작을 켜 두면 컴퓨터를 켤 때마다 저절로 떠요.
          6. Lively 설정 → 성능에서 "다른 앱이 화면을 가득 채우면 멈춤"을 고르면 수업 자료를 띄울 때 컴퓨터가 느려지지 않아요.
        • 맥 · Plash (무료)
          1. App Store에서 Plash를 설치해요.
          2. 메뉴 막대의 Plash 아이콘 → Add Website → 주소를 붙여 넣어요.
          3. 로그인은 Plash 메뉴의 Browsing Mode를 켜고 한 번 해요.
          4. Plash 설정의 Launch at Login을 켜면 맥을 켤 때마다 떠요.
        • 프로그램 없이 · 크롬 시작 화면
          1. 크롬 설정 → 시작 그룹 → 특정 페이지 또는 페이지 모음 열기에 주소를 넣어요.
          2. 크롬을 켜면 바로 교무실 타이쿤이 열려요. F11을 누르면 전체 화면, 한 번 더 누르면 돌아와요.
          3. 교실 TV · 전자칠판 · 두 번째 모니터에 띄워 두기 좋아요. 화면 위쪽 [⛶ 크게 보기]를 누르면 게임 화면만 가득 보여요.
        • 휴대폰 · 태블릿 홈 화면 아이폰은 사파리 공유 □↑ → 홈 화면에 추가, 갤럭시는 크롬 ⋮ → 홈 화면에 추가. 앱처럼 아이콘이 생겨요.

        이럴 땐 이렇게

        • 바탕화면에서 로그인이 안 돼요 바탕화면 프로그램 안에서는 구글 · 카카오 로그인 창이 막힐 수 있어요. 그럴 땐 크롬 시작 화면 방법이 가장 확실해요.
        • 로그인 없이도 되나요? 로그인 전에는 [먼저 둘러보기] 예시 화면이에요. 내 시간표로 움직이려면 한 번 로그인해 두세요. 한 번 로그인하면 다음부터는 저절로 들어와요.
        • 시간표를 바꿨는데 바탕화면은 그대로예요 바탕화면 위에서 새로고침(Lively는 배경을 다시 고르기)하면 바뀐 시간표로 움직여요.
        • 화면 모양 · 색 마지막으로 고른 화면(1~18)과 색은 내 계정에 저장돼서, 같은 계정으로 로그인한 바탕화면에서도 그대로 나와요.
